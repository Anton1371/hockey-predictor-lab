# Hockey Predictor Lab — Live

Бесплатная статическая панель для **виртуального** журнала прогнозов НХЛ/КХЛ. Сайт перечитывает `journal.json` каждые 15 секунд. Фоновый workflow примерно каждые 15 минут получает публичные табло НХЛ и КХЛ, обновляет подтверждённые статусы/счета и рассчитывает только уже зафиксированные поддерживаемые прогнозы. Никаких реальных ставок.

## Публикация бесплатно через GitHub Pages

1. Репозиторий должен быть публичным: `Anton1371/hockey-predictor-lab`.
2. В **Settings → Pages** выбери **Build and deployment → Source: GitHub Actions**.
3. В **Settings → Actions → General → Workflow permissions** разреши `Read and write permissions`, чтобы scheduled workflow мог сохранять обновления журнала.
4. В **Actions** разреши workflows, если GitHub попросит. Запуск публикации: **Deploy Hockey Predictor Lab**.
5. Сайт: https://anton1371.github.io/hockey-predictor-lab/
6. Для ручной проверки запусти **Update hockey scores and publish** через **Run workflow**. Автоматический запуск — примерно раз в 15 минут; GitHub может задерживать расписание.

## Что автоматизировано

- `index.html` перечитывает `journal.json` каждые 15 секунд и отображает банк, виртуальные ставки, результаты и ленту событий.
- `update_results.py` получает счёт и статус из публичного scoreboard NHL и публичного мобильного scoreboard КХЛ, сопоставляет матчи, обновляет счёт и статус.
- Поддерживаемые рынки `moneyline` и `total_over`/`total_under` рассчитываются только после того, как источник пометил матч завершённым и в журнале есть ранее зафиксированный прогноз.
- Новые матчи в пределах следующих 36 часов добавляются в журнал один раз. Если есть минимум три недавних завершённых матча на каждую команду, создаётся **простая эвристическая оценка формы по последним пяти играм**; это не ИИ-модель и не калиброванная вероятность.
- Новые прогнозы без независимо подтверждённого коэффициента всегда имеют ставку 0 ₽. Старые прогнозы, коэффициенты и ставки не изменяются.
- При изменении журнала workflow коммитит JSON и публикует сайт в том же запуске. Это важно, потому что коммиты от `GITHUB_TOKEN` сами по себе не запускают новые workflow на событии `push`.
- Букмекерские коэффициенты и live-ставки автоматически не создаются. Новые рассчитанные прогнозы отправляются в виде GitHub Issue; это не мобильный push и не SMS, и уведомления зависят от настроек GitHub Notifications пользователя.

## Правила виртуального банка

- Стартовый банк: 1 000 ₽.
- Ставки только виртуальные; реальные ставки не совершаются.
- Уже зафиксированные прогнозы, коэффициенты и суммы не меняются задним числом.
- При выигрыше прибыль = ставка × (коэффициент − 1); при проигрыше теряется ставка; при возврате P/L = 0.
- Открытые виртуальные ставки резервируются из свободного остатка.

## Ограничения и прозрачность

- Бесплатный режим, без платных API-ключей и секретов.
- Публичный репозиторий означает, что код и журнал доступны всем. Не добавляй личные данные или секреты.
- Автоматизация best-effort: GitHub Actions может запускаться с задержкой, а структура публичных scoreboard источников может измениться.
- Сайт обновляется после успешной записи и публикации новых данных, а не гарантированно в ту же секунду, когда изменился счёт.
- Если источник недоступен или формат данных не распознан, матч остаётся без подтверждённого счёта; скрипт не должен придумывать результат.
