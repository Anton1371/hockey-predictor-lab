# Hockey Predictor Lab — Live

Бесплатная статическая панель для **виртуального** журнала прогнозов НХЛ/КХЛ. Сайт перечитывает `journal.json` каждые 15 секунд. Публичный NHL scoreboard updater проверяет окончательные/текущие счета через официальный публичный endpoint NHL и обновляет JSON при подтверждённых изменениях. Никаких реальных ставок.

## Публикация бесплатно через GitHub Pages

1. Создай отдельный **public** репозиторий `hockey-predictor-lab` в GitHub.
2. Распакуй архив и загрузи **содержимое** папки `hockey-predictor-lab-ready` в корень репозитория: `index.html`, `journal.json`, `update_results.py`, `README.md`, `.gitignore` и папку `.github/workflows/`.
3. В репозитории открой **Settings → Pages** и выбери **Build and deployment → Source: GitHub Actions**.
4. Открой **Settings → Actions → General → Workflow permissions** и разреши `Read and write permissions` для `GITHUB_TOKEN`, чтобы scheduled workflow мог коммитить подтверждённые обновления журнала.
5. Перейди во вкладку **Actions**. Разреши workflows, если GitHub попросит. Запусти **Deploy Hockey Predictor Lab** через `Run workflow`.
6. После успешного деплоя сайт будет доступен по адресу `https://<твой-GitHub-логин>.github.io/hockey-predictor-lab/`.
7. Затем запусти **Update hockey scores and publish** вручную один раз, чтобы проверить доступ к публичному табло NHL. В дальнейшем он запускается примерно каждые 15 минут; GitHub может задерживать расписание.

## Что автоматизировано

- `index.html` перечитывает `journal.json` каждые 15 секунд и отображает банк, ставки, результаты и ленту событий.
- `update_results.py` сопоставляет записи с командами по кодам NHL API, обновляет счёт и статус, а также рассчитывает поддерживаемые рынки `moneyline` и `total_over`/`total_under` только после финального статуса.
- Если журнал изменился, workflow сохраняет новый JSON и публикует обновлённую версию Pages в том же запуске. Это важно: коммиты от `GITHUB_TOKEN` сами по себе не запускают новые workflow на событии `push`.
- КХЛ пока **не обновляется автоматически**: в проекте нет настроенного и проверенного источника для автоматического импорта её результатов.
- Новые ИИ-прогнозы, live-коэффициенты букмекеров и push-уведомления не подключены. Не считай их автоматизированными, пока не добавлен и не протестирован отдельный источник/механизм.

## Правила виртуального банка

- Стартовый банк: 1 000 ₽.
- Ставки — только виртуальные; никакие реальные ставки не совершаются.
- Уже зафиксированные прогнозы, коэффициенты и суммы не меняются задним числом.
- При выигрыше прибыль = ставка × (коэффициент − 1); при проигрыше теряется ставка; при возврате P/L = 0.
- Открытые виртуальные ставки резервируются из свободного остатка.

## Ограничения

- Бесплатный режим, без платных API-ключей и секретов.
- Публичный репозиторий означает, что исходный код и журнал доступны всем. Не добавляй сюда личные данные или секреты.
- Автоматизация best-effort: GitHub Actions может запускаться с задержкой, а структура публичного endpoint может измениться.
- Сайт обновляется после успешной записи и публикации новых данных, а не гарантированно в ту же секунду, когда изменился счёт.
